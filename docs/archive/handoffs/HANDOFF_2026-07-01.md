# In server/code/api/services/lori_response_guards.py:
#   Split the accent regex into two tiers:
_SPANISH_UNIQUE_CHARS_RX = re.compile(r"[ñÑ¿¡]")   # unambiguously Spanish
_LATIN_ACCENT_CHARS_RX   = re.compile(r"[áéíóúÁÉÍÓÚ]")  # French/Italian/PT too

def _looks_spanish(text: str) -> bool:
    if not text:
        return False
    if _SPANISH_UNIQUE_CHARS_RX.search(text):
        return True                       # ñ / ¿ / ¡ alone → Spanish
    matches = _SPANISH_ONLY_WORDS_RX.findall(text)
    n_words = len(set(m.lower() for m in matches))
    if _LATIN_ACCENT_CHARS_RX.search(text):
        return n_words >= 1                # accent + ≥1 Spanish word
    return n_words >= 2                    # no accent → ≥2 Spanish words

## Known operational gotchas

### Edit tool truncates on multi-byte UTF-8

Direct experience during 2026-06-25 and 2026-07-01 sessions: the `Edit` tool has a bad habit of truncating writes mid-string when the replacement text contains French/Italian/Czech accents (`é`, `ô`, `č`, etc.). Symptoms: file ends mid-line, AST parse fails with `SyntaxError: '(' was never closed`. **Workaround: use bytes-level Python via `mcp__workspace__bash`:**

```bash
python3 <<'PYEOF'
path = 'server/code/api/services/lori_response_guards.py'
with open(path, 'r', encoding='utf-8') as f:
    text = f.read()
old = '...old content...'
new = '...new content...'
assert text.count(old) == 1
text = text.replace(old, new, 1)
with open(path, 'w', encoding='utf-8') as f:
    f.write(text)
PYEOF
```

If it truncates anyway, restore from HEAD:

```bash
git cat-file -p HEAD:path/to/file.py > /tmp/restore.py
cp /tmp/restore.py path/to/file.py
```

Then re-apply changes via the same bytes-level Python pattern.

### Git from the sandbox leaves index locks

Do NOT run `git status`, `git add`, `git commit` from `mcp__workspace__bash`. They leave a `.git/index.lock` the sandbox cannot delete, and Chris's WSL git operations then fail. **`git cat-file -p HEAD:path`** is safe (read-only). **Everything else — hand Chris a WSL copy-paste block.**

### Chris commits via GitHub Desktop, not WSL git push

Per `CLAUDE.md`: prepare copy-paste `git add` + `git commit` blocks for WSL. Do NOT include `git push` — Chris pushes via GitHub Desktop.
