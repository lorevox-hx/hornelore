# HISTORICAL CONTEXT — SUPERSEDED BY RUNTIME ARCHITECTURE

**Archival status:** This document is preserved as the vision document
that triggered the current Story-First Runtime Architecture. It is no
longer the source of truth for what gets built or how.

**For current architecture, see:**

- `HORNELORE-UNIVERSAL-PIVOT-STRATEGY.md` — answers *who is Lori for
  and what kind of project is this*
- `LORI-RUNTIME-ARCHITECTURE.md` — answers *what is the control flow
  that produces Lori's behavior*. Defines the nine-stage pipeline that
  this document's Part 7 sketched.

**For implementation, see:**

- `WO-LORI-SAFETY-PAST-TENSE-ACKNOWLEDGE-01` — safety classifier
  extension (Part 2 of original mode list, Safety / Softened)
- `WO-LORI-SOFTENED-MODE-PERSISTENCE-01` — softened-mode state
  machine (Part 2 of original mode list, Safety / Softened)
- `WO-LORI-PHASE-9-DISCLOSURE-UPDATE-01` — consent disclosure
  matching the actual behaviors
- `WO-LORI-STORY-FIRST-PHASE-1-01` — reflection-first + story
  interruption rules + thread banking + question hierarchy
  (Parts 4, 5, 3, and the question ladder of this document)
- `WO-LORI-ORAL-HISTORY-DEFAULT-01` — flips oral-history as the
  default session style (matches this document's posture argument)
- `WO-LORI-BIO-BUILDER-UNIVERSAL-01` — universal Bio Builder via
  chapter extraction + anchored asking + documents + operator entry
  (resolves the question this document's Part 6 raised about
  biography as scaffolding)

**Resolution of this document's seven proposed turn modes:**

| Original mode | Resolution |
|---|---|
| Orientation | Absorbed into Layer 1 (open recall) of question hierarchy |
| Story Capture | Replaced by momentum + Layer 3-4 suppression + thread bank |
| Timeline Anchor | Replaced by bio anchored asker (chapter-anchored) + Layer 3 of hierarchy |
| Memory Echo | Pending — own WO when narrator-facing surface is built |
| Clarification | Absorbed into Layer 4 of question hierarchy |
| Companion | Existing session style, operator-selectable |
| Safety / Softened | Implemented by past-tense + softened-mode-persistence WOs |

See `LORI-RUNTIME-ARCHITECTURE.md` "Resolution of the original
turn-mode list" for full detail.

**Why this document is preserved rather than deleted:** the vision
language here is clearer than the spec language in the implementation
WOs. New contributors should read this document first to understand
*why* the system was built this way, then move to the runtime
architecture doc to understand *what* the system actually does.
